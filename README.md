# 月兎プッシャー (Moon Rabbit Pusher)

物理演算で動く 3D メダルプッシャーに、ローグライクのラン構造を組み合わせたブラウザゲームです。
新月から満月まで、八つの夜のノルマを払い出しで越えていきます。

**遊ぶ:** https://nakanaka0318.github.io/coin-game/

## 遊び方

- 画面をクリック/タップした横位置からメダルを投入します。長押しで連続投入。
- メダルはステージの釘を抜けてプッシャーへ落ち、手前の縁から落ちたものが払い出し (持ちメダルに加算) になります。横に落ちたメダルは没収です。
- ステージ中央の **鳥居** をメダルがくぐると液晶スロットの抽選 (保留) が貯まります。
  | 出目 | 効果 |
  | --- | --- |
  | 7 7 7 | ジャックポット (貯まった枚数のメダルの雨) |
  | 満月 | 月玉 (大きな玉) が降ってくる。手前に落とせば 10 枚 + 抽選 |
  | 兎 | メダル 12 枚の雨 |
  | 団子 | メダル 4 枚の雨 |
  | 星 | 金メダル (3 枚分) |
  | 桜 | 今夜のメダル +2 |

### ラン (ローグライク)

- 各夜には **今夜のメダル** (その夜に配られる投入用メダル) と **上納ノルマ** があります。
- 払い出しは持ちメダルに入ります。その夜の **収支** (払い出し − 追加投入) がノルマに届けば、夜明けにノルマ分を月へ上納して次の夜へ。届かなければランは終わりです。
- 今夜のメダルを使い切ったら、持ちメダルから10回まで追加投入できます (最後の投入から数秒で夜が明けます)。
- 夜によっては **縁起** (追い風、霧、狐火、大入りなど) が付き、第4夜と第8夜はボスの夜です。
- 夜明けの後は **夜店**。上納の残りの持ちメダルで買い物をします。
  - **お守り** (最大5つ): ラン中ずっと効きます。側壁の延長、金メダル化、双子投入、鳥居の拡幅、磁石、補充、スロット強化など21種。
  - **お札** (2〜3枚): 夜の間に一度だけ使える消耗品。地震、突風、金貨、月玉、雨乞、払出2倍、保留追加。
- フリープレイではノルマなしで遊べます。進行はブラウザに自動保存されます。

### 操作

| 操作 | キーボード | マウス/タッチ |
| --- | --- | --- |
| 投入位置 | `←` `→` / `A` `D` | ポインタの横位置 |
| 投入 (長押しで連続) | `Space` / `Enter` | クリック / タップ |
| お札を使う | `1` `2` `3` | 右側のお札 |
| 視点切替 | `V` | 「視」ボタン |
| 消音 | `M` | メニュー |
| メニュー | `Esc` | 「≡」ボタン |

## 技術

- 描画: [three.js](https://threejs.org/) (インスタンス描画、PCF シャドウ、ブルーム)。テクスチャ (メダルの浮き彫り、青海波、月、提灯、液晶) はすべてキャンバスで生成しています。
- 物理: [Rapier](https://rapier.rs/) (WebAssembly、SIMD 版を優先し非対応ブラウザでは通常版)。メダルは円柱コライダ、プッシャーはキネマティック剛体です。
- 音: Web Audio で合成 (メダルの金属音、琴の撥弦 (Karplus-Strong)、太鼓、りん)。音声ファイルは使っていません。
- ゲームロジック (`src/game`) は DOM に依存しないため、Node 上で実物の物理と一緒にシミュレーションしてバランス調整しています。

```
src/
  sim/      物理ワールド、筐体の形状、初期盤面 (initial-field.json)
  game/     ルール、ラン進行、お守り・お札・夜のデータ、乱数
  render/   シーン、筐体、メダル、液晶、パーティクル、テクスチャ
  audio/    効果音と音楽の合成
  ui/       HUD と各画面
tools/      ヘッドレスのシミュレーション・バランス調整・スクリーンショット
```

## 開発

```sh
npm install
npm run dev      # http://127.0.0.1:5173/
npm run build    # dist/ に静的ファイルを出力
```

ヘッドレス調整用スクリプト:

```sh
node tools/sim-test.mjs 320 40          # 物理の負荷と安定性
node tools/balance.mjs steady 500 0.5   # 1投入あたりの払い出し率
AIM=mid node tools/balance.mjs run 3     # ボットによるラン
node tools/bake-field.mjs 600           # 初期盤面の再生成
```

## 公開

`main` に push すると GitHub Actions (`.github/workflows/deploy.yml`) がビルドし、`dist/` を `gh-pages` ブランチへ公開します。GitHub Pages の公開元は `gh-pages` ブランチの `(root)` です。
