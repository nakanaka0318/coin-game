# 月兎プッシャー (Moon Rabbit Pusher)

物理演算で動く 3D メダルプッシャーに、ローグライクのラン構造を組み合わせたブラウザゲームです。
新月から満月まで、八つの夜のノルマを払い出しで越えていきます。

**遊ぶ:** https://nakanaka0318.github.io/coin-game/

## 遊び方

- 筐体の左右に **ピッチャー** があります。狙いを左右に動かし、タップ (クリック) で発射、長押しで連射します。左右のピッチャーが交互にメダルを放物線で撃ち出し、狙った位置の上段ステージ (フェルト) に着地させます。
- メダルは左右に揺れる **ポール (釘)** の間を抜けてプッシャーへ落ちます。
- 手前から落ちたメダルは、左右に動く **お賽銭箱** に入ったものだけが払い出しになります。箱は落ちそうなメダルを自動で追いかけます。箱の外に落ちたメダルは没収です。
- ステージ中央をゆっくり左右に動く **鳥居** をくぐると液晶スロットの抽選 (保留、最大4) が貯まります。
  - 鳥居の前では **鈴** が大きく揺れていて、当たったメダルは弾かれます。鈴が外れた瞬間を狙うのがコツです。
  - 保留ランプの色 (白 → 青 → 緑 → 赤 → 金 → 虹) が期待度です。
  - リーチ、スーパーリーチ (月の兎が餅をつく)、全回転、ハズレからの復活、すべり、などの演出があります。
  - 7 か満月が揃うと **フィーバー**。数回転のあいだ当たりやすくなり、プッシャーが速く動いてメダルの雨も増えます。フィーバー中にもう一度揃うと回転数が補充されます (連チャンは3回まで)。

  | 出目 | 効果 |
  | --- | --- |
  | 7 7 7 | ジャックポット (貯まった枚数のメダルの雨) + フィーバー |
  | 満月 | 月玉 (大きな玉) + フィーバー。箱に入れば 10 枚 + 抽選 |
  | 兎 | メダル 16 枚の雨 |
  | 団子 | メダル 6 枚の雨 |
  | 星 | 金メダル (3 枚分) |
  | 桜 | 今夜のメダル +3 |

### ラン (ローグライク)

- 各夜には **今夜のメダル** (その夜に配られる発射用メダル) と **上納ノルマ** があります。
- 払い出しは持ちメダルに入ります。その夜の **払い出し** がノルマに届けば、夜明けにノルマ分を持ちメダルから月へ上納して次の夜へ進みます。届かなければランは終わりです。
- 今夜のメダルを使い切ったら、持ちメダルを1枚ずつ使って10回まで追加で撃てます。足りない夜を助ける貯金の使い道です。
- 夜の始まりには、台の空いたところへ月兎がメダルを1層だけ補充します。
- 夜によっては **縁起** (追い風、霧、狐火、大入り、居眠り箱、お祭りなど) が付きます。
- 第4夜と第8夜は **ボスの夜** です。着地点の上にボスが浮かび、狙いを合わせてメダルを当てると体力が減ります (銀1・金3・小判8)。生きている間は邪魔をしてきて、退治するとご褒美と月の欠片がもらえます。

  | ボス | 夜 | 体力 | 妨害 | 退治のご褒美 |
  | --- | --- | --- | --- | --- |
  | 赤鬼 | 第4夜 | 24 | お賽銭箱に入ったメダルを3枚に1枚横取り | メダル10枚 + 横取り分の倍 + 金メダル2枚 |
  | 化け狸 | 第6夜 (月蝕 三〜) | 30 | お賽銭箱の動きが鈍る | メダル15枚 + 金メダル3枚 |
  | 大天狗 | 第8夜 | 50 | 9秒ごとに天狗風で台のメダルを横へ吹き飛ばす | メダル30枚 + 金メダル4枚 |

- 夜明けの後は **夜店** で、上納の残りの持ちメダルを使って買い物をします。
  - **お守り** (最大5つ): ラン中ずっと効きます。側壁の延長、金メダル化、双子発射、鳥居の拡幅、磁石、大きな賽銭箱、韋駄天、スロット強化など24種。
  - **お札** (2〜3枚): 夜の間に一度だけ使える消耗品です。地震、突風、金貨、月玉、雨乞、払出2倍、保留追加、祭 (即フィーバー) の8種。
  - 夜店では手持ちのお守りとお札の効果、月の社とお守り込みの今の能力も確認できます。

### 月蝕 (難易度)

満月を越えると、より難しい **月蝕** が一段ずつ解放されます。タイトルで選べ、上の段ほど下の段のルールが重なります。月の欠片は段ごとに ×1.3, ×1.6 … と増えます。

| 段 | 追加されるルール |
| --- | --- |
| 月蝕 一 | ノルマ +20% |
| 月蝕 二 | 夜店の値段 +30%、品替え +1枚、ボスの体力 +50%、ノルマさらに +20% |
| 月蝕 三 | 第6夜に化け狸が現れ、ノルマさらに +15% |
| 月蝕 四 | 鳥居の鈴が大きく速くなり、今夜のメダル −3枚、ノルマさらに +20% |
| 月蝕 五 | 毎晩、悪い縁起がもうひとつ重なり、金メダルの価値 −1枚、ノルマさらに +25% |

### 月の社 (ローグライト強化)

ランが終わると、進んだ夜の数とボス退治に応じて **月の欠片** がもらえます (満月まで越えるとボーナス)。欠片はタイトルの「月の社」で永続強化に使えます。段階のある強化は、買うたびに強くなり値段も上がります。

| 強化 | 内容 |
| --- | --- |
| ピッチャーの連射 | 長押しの連射間隔が短くなる (8段階) |
| ピッチャーの振り向き | 狙いへ向き直る速さ (6段階) |
| お賽銭箱の速さ / 大きさ | 箱の移動速度と幅 (各8段階) |
| 金メダルの出現率 | 3枚分の金メダルを撃つ確率 (8段階) |
| 虹の小判 | 20枚分の虹色の小判を撃つようになる |
| 夜店の目利き | 品替えが安くなり、毎回1度は無料 |
| 大鳥居 | 鳥居が少し大きくなる |
| お賽銭返し | 箱に入らなかったメダルも、30%で1枚戻ってくる |
| ほか | 軍資金、今夜のメダル増量、保留の数珠、月玉の加護、フィーバー延長、お札の授かり、夜店の品揃え、お守り袋 |

フリープレイではノルマなしで遊べます。進行と強化はブラウザに自動保存されます。

メニューの設定で、全体・効果音・BGM の音量をそれぞれ調整できます (BGM の初期値は 50%)。

## 技術

- 描画: [three.js](https://threejs.org/) (インスタンス描画、PCF シャドウ、ブルーム)。テクスチャ (メダルの浮き彫り、青海波、月、提灯、液晶) はすべてキャンバスで生成しています。
- 物理: [Rapier](https://rapier.rs/) (WebAssembly、SIMD 版を優先し非対応ブラウザでは通常版)。メダルは円柱コライダ、プッシャー・ポール・鳥居・鈴・ボス・お賽銭箱はキネマティック剛体です。ボスへの命中は衝突イベントで判定しています。ピッチャーは着地点から逆算した放物線の初速でメダルを撃ち出します。
- 音: Web Audio で合成 (メダルの金属音、琴の撥弦 (Karplus-Strong)、太鼓、りん)。音声ファイルは使っていません。
- ゲームロジック (`src/game`) は DOM に依存しないため、Node 上で実物の物理と一緒にシミュレーションしてバランス調整しています。

```
src/
  sim/      物理ワールド、筐体の形状、初期盤面 (initial-field.json)
  game/     ルール、ラン進行、お守り・お札・夜のデータ、乱数
  render/   シーン、筐体、メダル、液晶、パーティクル、テクスチャ
  audio/    効果音と音楽の合成
  ui/       HUD と各画面
tools/      ヘッドレスのシミュレーション・バランス調整・スクリーンショット
```

## 開発

```sh
npm install
npm run dev      # http://127.0.0.1:5173/
npm run build    # dist/ に静的ファイルを出力
```

ヘッドレス調整用スクリプト:

```sh
node tools/sim-test.mjs 60                       # 物理の負荷と安定性
node tools/balance.mjs steady 500 0.5            # 1発あたりの払い出し率と箱の捕獲率
AIM=track node tools/balance.mjs run 3           # ボットによるラン
META="boxSize=3,fireRate=2" node tools/balance.mjs run 3   # 月の社の強化込み
ECLIPSE=2 AIM=track node tools/balance.mjs run 3   # 月蝕 二で
node tools/bake-field.mjs 600                    # 初期盤面の再生成
```

## 公開

`main` に push すると GitHub Actions (`.github/workflows/deploy.yml`) がビルドし、`dist/` を `gh-pages` ブランチへ公開します。GitHub Pages の公開元は `gh-pages` ブランチの `(root)` です。
